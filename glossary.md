# Słownik domenowy

Słownik domenowy (*Domain Glossary*) definiuje pojęcia używane w projekcie, aby wszyscy członkowie zespołu rozumieli je w ten sam sposób.

Pojęcia opisujemy językiem dziedziny, dla której tworzymy system, a nie językiem technologii.

## Pojęcia

| Pojęcie | Definicja |
|---|---|
| Student | Osoba ucząca się na uczelni wyższej, która może korzystać ze zniżek i promocji dostępnych dla studentów. |
| Oferta | Propozycja produktu, usługi lub innego świadczenia dostępnego dla studentów na określonych warunkach, często z uwzględnieniem rabatu. |
| Kampus | Wydzielony obszar uczelni obejmujący budynki i inne obiekty związane z jej działalnością. |
| Interaktywna Mapa Zniżek Studenckich | Mapa umożliwiająca studentom wyszukiwanie i przeglądanie ofert zniżek studenckich według lokalizacji oraz wybranych kryteriów. |
| Aktualna promocja | Oferta promocyjna, której okres obowiązywania jeszcze się nie zakończył i której warunki pozwalają na skorzystanie z niej. |
| Legitymacja studencka | Dokument potwierdzający status studenta, umożliwiający korzystanie ze zniżek i uprawnień przysługujących studentom. |
| Internet | Globalna sieć komputerowa umożliwiająca przesyłanie danych oraz korzystanie z usług i zasobów online, w tym z systemu mapy zniżek. |
| Agent | Podmiot lub osoba odpowiedzialna za dostarczanie, aktualizowanie albo weryfikowanie informacji o ofertach i promocjach w systemie. |
| Filtrowanie | Proces ograniczania wyświetlanych ofert na podstawie określonych kryteriów, takich jak lokalizacja, odległość, rodzaj oferty lub wysokość rabatu. |
| Wydział | Jednostka organizacyjna uczelni odpowiedzialna za określony obszar kształcenia lub działalności naukowej. |
| Odległość | Dystans pomiędzy dwoma lokalizacjami, np. pomiędzy położeniem studenta a miejscem realizacji oferty. |
| Lokalizacja | Położenie geograficzne miejsca, w którym dostępna jest oferta, określone np. za pomocą adresu lub współrzędnych geograficznych. |
| Procentowa wielkość rabatu | Wartość procentowa określająca, o ile procent cena produktu lub usługi jest niższa od ceny pierwotnej. |
