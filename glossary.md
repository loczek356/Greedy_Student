# Słownik domenowy

Słownik domenowy (*Domain Glossary*) definiuje pojęcia używane w projekcie, aby wszyscy członkowie zespołu rozumieli je w ten sam sposób.

Pojęcia opisujemy językiem dziedziny, dla której tworzymy system, a nie językiem technologii.

## Pojęcia

| Pojęcie | Definicja |
|---|---|
| Student | Osoba ucząca się na uczelni wyższej, która może korzystać ze zniżek dostępnych dla studentów. |
| Oferta | Propozycja produktu, usługi lub innego świadczenia dostępnego dla studentów na określonych warunkach, która może obejmować zniżkę. |
| Kampus | Wydzielony obszar uczelni obejmujący budynki i inne obiekty związane z jej działalnością. |
| Interaktywna Mapa Zniżek Studenckich | Mapa umożliwiająca studentom wyszukiwanie i przeglądanie ofert zniżek studenckich według lokalizacji oraz wybranych kryteriów. |
| Zniżka | Obniżenie ceny produktu lub usługi względem ceny pierwotnej, wyrażone kwotowo lub procentowo, dostępne na określonych warunkach i w określonym okresie. |
| Legitymacja studencka | Dokument potwierdzający status studenta, umożliwiający korzystanie ze zniżek i uprawnień przysługujących studentom. |
| Internet | Globalna sieć komputerowa umożliwiająca przesyłanie danych oraz korzystanie z usług i zasobów online, w tym z Interaktywnej Mapy Zniżek Studenckich. |
| Agent | Podmiot lub osoba odpowiedzialna za dostarczanie, aktualizowanie albo weryfikowanie informacji o ofertach i zniżkach w systemie. |
| Filtrowanie | Proces ograniczania wyświetlanych ofert na podstawie określonych kryteriów, takich jak lokalizacja, odległość, rodzaj oferty lub wysokość zniżki. |
| Wydział | Jednostka organizacyjna uczelni odpowiedzialna za określony obszar kształcenia lub działalności naukowej. |
| Odległość | Dystans pomiędzy dwoma lokalizacjami, np. pomiędzy położeniem studenta a miejscem realizacji oferty. |
| Lokalizacja | Położenie geograficzne użytkownika lub miejsca, w którym dostępna jest oferta, określone np. za pomocą adresu lub współrzędnych geograficznych. |
| Budżet | Środki finansowe, którymi student dysponuje i które może przeznaczyć na produkty oraz usługi. |
| Okres obowiązywania zniżki | Przedział czasu, w którym dana zniżka jest dostępna. |
| Warunki zniżki | Zasady określające, kiedy i w jaki sposób można skorzystać z danej zniżki, np. konieczność okazania legitymacji studenckiej. |
