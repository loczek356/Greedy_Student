# UC-01 — Wyszukiwanie najbliższych ofert ze zniżkami studenckimi

## Aktor

Student

## Cel

Znalezienie najbliższych restauracji, kawiarni, barów lub muzeów oferujących zniżki studenckie.

## Powiązane wymagania

FR-01, FR-02, FR-03, FR-04, FR-08

## Warunek wstępny

System posiada aktualne informacje o ofertach ze zniżkami studenckimi oraz ich lokalizacjach.

## Scenariusz podstawowy

1. Student otwiera Interaktywną Mapę Zniżek Studenckich.
2. Student udostępnia swoją lokalizację lub wybiera lokalizację ręcznie.
3. System pobiera lokalizację studenta.
4. System wyszukuje najbliższe oferty ze zniżkami studenckimi.
5. System prezentuje znalezione oferty na interaktywnej mapie.
6. Student wybiera interesującą go ofertę.
7. System wyświetla szczegółowe informacje o ofercie, w tym wysokość zniżki i warunki jej uzyskania.

## Scenariusze alternatywne

- **2a. Student nie udostępnia lokalizacji:** System umożliwia ręczne wskazanie lokalizacji.
- **4a. Nie znaleziono ofert:** System informuje studenta o braku dostępnych ofert w wybranej lokalizacji.
- **6a. Oferta przestała obowiązywać:** System informuje studenta, że oferta jest nieaktualna.
