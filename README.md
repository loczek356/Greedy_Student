# Greedy Student

**Interaktywna Mapa Zniżek Studenckich** - aplikacja stworzona dla studentów zmagających się z ograniczonym budżetem, która w jednym miejscu gromadzi aktualne i zweryfikowane rabaty w pobliżu kampusu. Pomaga szybko znaleźć między innymi tani obiad, szybką kawę między wykładami czy tańsze wyjście do muzeum w czasie rzeczywistym.

Szczegółowy opis założeń projektu znajdziesz w dokumencie [vision.md](vision.md).

## Główne funkcje

- **Interaktywna mapa zniżek** - prezentacja lokalizacji restauracji, kawiarni, barów i muzeów oferujących rabaty studenckie wraz ze szczegółami oraz warunkami uzyskania zniżki.
- **Zaawansowane filtrowanie i lokalizacja** - wyszukiwanie najbliższych ofert na podstawie aktualnej lokalizacji studenta lub wybranego wydziału oraz filtrowanie według kategorii, odległości i procentowej wysokości rabatu.
- **Automatyczny agent ofert** - moduł cyklicznie przeszukujący Internet w celu znajdowania nowych promocji, weryfikowania ich wiarygodności oraz aktualizowania bazy na mapie.
